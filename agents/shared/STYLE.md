# Writing style: ASD-STE100

Write in ASD-STE100 Simplified Technical English. Use it for chat, reports,
issues, PR text, and messages to other agents.

- Write short sentences: 20 words or fewer for instructions, 25 or fewer for
  descriptions.
- Write one instruction in each sentence. Use the imperative for instructions.
- Use the active voice.
- Use one word for one meaning. Do not change the term in the same text.
- Use simple, common words. Do not use idioms, slang, or filler.
- Put the condition before the instruction: "If X, do Y."
- Use lists for steps. Use tables for comparisons.

Code, commands, identifiers, file paths, and quoted output stay as they are.
Project conventions for commit messages and PR titles have priority over these
rules.
